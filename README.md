## HolaMundo
Proyecto Java para practicar el control de versiones con Git y la colaboración mediante Github

## Objetivos 
- Crear un programa Java.
- Guardar cambios mediante commits.
- Trabajar con ramas y resolver conflictos.
- Compartir el proyecto mediante un repositorio remoto en GitHub.
## Colaboracion en equipo
Este proyecto se desarrolla entre dos compañeros utilizando Git y GitHub
